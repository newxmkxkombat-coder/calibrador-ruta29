# Calibrador Ruta 29 (Neiva)

App web para ir pendiente del tiempo en los puntos de control de la Ruta 29:
Polideportivo, Las Vegas, Caldo Parao, Antonio Nariño y Palmas.

- Usa el GPS del celular para saber cuánto falta al próximo punto.
- Dice si vas adelantado o atrasado (meta: 2 a 3 minutos de adelanto).
- Avisa por voz.
- Tiene modo prueba para ver cómo funciona sin estar en la ruta.

Se abre desde GitHub Pages (https), que es lo que permite usar el GPS.
